# みきのマイカレンダー 🌸

生理と有給をかわいく記録する、美樹さん専用のカレンダーアプリ（PWA）。

## 使い方

- 日をタップして記録する（選んだら自動保存）
  - 生理：△ 少ない / ● ふつう / ✕ 多い
  - お休み：○ 有給（1日）/ ◐ 半日有給（0.5日）
  - マイ項目：自分で追加した項目（病院・旅行など）
  - メモ
- ○ 有給を入れるたびに、画面一番上の「有給残り」が自動で減る
- 「データを見る」スイッチで、前回の生理から何日目か・平均周期・次回予測を表示
  - 次回予測日はカレンダーに薄ピンクの点線で表示される
- マイ項目は「マーク」と「色」を選んでいつでも追加・削除できる
- 有給の付与日数は「設定・バックアップ」で変更できる
- データは端末の localStorage に保存。バックアップ保存（JSON）／読込に対応

## 技術

- 単一HTML（index.html）+ manifest + Service Worker
- サーバーなし・GitHub Pagesで配信
